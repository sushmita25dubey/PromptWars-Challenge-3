## 🌍 Overview

EcoTracker AI is a modern sustainability platform designed to help users measure, analyze, and improve their carbon footprint. The platform combines AI-driven insights, carbon analytics, eco-friendly action plans, and community engagement to encourage sustainable living.

Built as part of **PromptWars Challenge 3 – Carbon Footprint Awareness Platform**.

Many individuals want to adopt sustainable habits but lack awareness of:

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/sushmita25dubey/EcoTracker-AI.git
```

### Navigate to Project

```bash
cd EcoTracker-AI
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build Production Version

```bash
npm run build
```
